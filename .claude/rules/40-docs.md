# 40-docs (보조)

- `.docs/`는 도메인 정본. 새 문서를 만들면 `.docs/00_INDEX.md` 표에 한 줄. 같은 내용을 두 곳에 쓰지 않는다.
- 한 파일(`00_도메인.md`)이 약 30KB를 넘거나 영역이 3개 이상이면 `00_도메인/00-NN_*.md`, `NN_<영역>/NN-MM_*.md`로 나눈다(색인 참고).
- 업무 규칙 ID(`R-NN`)는 바꾸지 않는다. 바뀐 결정은 ~~취소선~~ + 「대체됨(날짜, 과제 id)」.
- `.harness/context.md`는 3KB 이하, 흐름·위치만. 끝난 줄은 지운다.
- 둘 다 Codex가 읽을 수 있다 — 비공개 기준의 파일명·경로를 쓰지 않는다(guard 차단).
